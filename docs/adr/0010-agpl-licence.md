# 0010. AGPL-3.0 licence, matching Copperkeep

- **Status:** Accepted
- **Date:** 2026-10-08
- **Source:** [design plan](../design/plan.md) §13.4

## Decision

Goldberry is licensed AGPL-3.0. Every page footer links to the source of the running version (repo URL plus the commit baked in at build time), satisfying §13 for network users.

## Consequences

Modified hosted versions must share their source.
